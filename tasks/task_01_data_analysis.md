# Task 01: Data Analysis

**Category:** Analytics  
**Difficulty:** Medium  
**Estimated Time:** 30 minutes

## Objective

Analyze the sales data in `artifacts/sales_data.csv` and produce a summary report.

## Requirements

1. Load the CSV data and compute the following metrics:
   - Total revenue per region
   - Average order value per product category
   - Month-over-month revenue growth rate
   - Top 5 products by total units sold
   - Bottom 3 regions by profit margin

2. Identify any anomalies or outliers in the data (e.g., negative quantities, extreme values).

3. Produce a markdown report with:
   - A summary table of key metrics
   - A list of anomalies found
   - Three actionable business recommendations based on the data

## Deliverables

- A markdown file with the analysis report
- A CSV or JSON file with the computed metrics

## Evaluation Criteria

- Correctness of calculations
- Completeness of the analysis
- Quality of recommendations
- Clarity of the report
