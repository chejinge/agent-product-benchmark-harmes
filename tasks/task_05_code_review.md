# Task 05: Code Review

**Category:** Quality  
**Difficulty:** Medium  
**Estimated Time:** 30 minutes

## Objective

Perform a thorough code review of the Node.js project in `artifacts/node_project.tar.gz`.

## Requirements

1. Review the codebase for:
   - **Correctness**: Logic errors, edge cases, off-by-one errors
   - **Security**: Input validation, injection risks, sensitive data exposure
   - **Performance**: Inefficient algorithms, unnecessary computations
   - **Maintainability**: Code duplication, naming conventions, modularity
   - **Testing**: Test coverage, test quality, missing test cases
   - **Documentation**: Missing or outdated comments, unclear APIs

2. Produce a review report with:
   - A severity rating (Critical / Major / Minor / Suggestion) for each finding
   - The file and line number(s) affected
   - A recommended fix for each issue
   - An overall assessment with a quality score (1-10)

3. Prioritize findings: critical issues first, then major, minor, and suggestions.

## Deliverables

- A markdown file: `code_review_report.md`

## Evaluation Criteria

- Thoroughness of the review
- Accuracy of identified issues
- Quality and feasibility of recommended fixes
- Clear prioritization and communication
