# Task 04: Report Generation

**Category:** Documentation  
**Difficulty:** Medium  
**Estimated Time:** 40 minutes

## Objective

Generate a comprehensive quarterly business report from the sales data.

## Requirements

1. Using `artifacts/sales_data.csv`, create a quarterly report that includes:
   - Executive summary (3-5 sentences)
   - Revenue breakdown by region (table)
   - Product category performance comparison (table)
   - Month-over-month trend analysis
   - Key performance indicators with year-over-year comparison placeholders
   - Risk factors and mitigation strategies

2. Format the report as a well-structured markdown document with:
   - Proper heading hierarchy
   - Tables for tabular data
   - Bold/italic for emphasis where appropriate
   - A table of contents

3. Include an appendix with methodology notes.

## Deliverables

- A single markdown file: `quarterly_report_q4_2025.md`

## Evaluation Criteria

- Report structure and formatting
- Accuracy of derived metrics
- Quality of executive summary and recommendations
- Professional tone and presentation
