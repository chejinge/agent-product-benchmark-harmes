# Scoring Rubric

Each task is evaluated on four dimensions, each scored 0-10.

## Dimensions

### 1. Correctness (weight: 40%)
Does the solution produce the right output? Are edge cases handled?

| Score | Description |
|-------|-------------|
| 0     | Completely wrong or no output |
| 3     | Partially correct, major errors |
| 5     | Mostly correct, minor errors |
| 7     | Correct on happy path, some edge cases missed |
| 10    | Fully correct including all edge cases |

### 2. Completeness (weight: 25%)
Are all parts of the task addressed? Are there missing steps or sections?

| Score | Description |
|-------|-------------|
| 0     | Task not attempted |
| 3     | Less than half completed |
| 5     | Major parts done, some missing |
| 7     | Nearly complete, minor omissions |
| 10    | Fully complete |

### 3. Clarity (weight: 20%)
Is the solution well-structured, documented, and easy to follow?

| Score | Description |
|-------|-------------|
| 0     | Unreadable or no explanation |
| 3     | Hard to follow, minimal docs |
| 5     | Adequate structure, some docs |
| 7     | Well-organized, good docs |
| 10    | Exemplary clarity and documentation |

### 4. Efficiency (weight: 15%)
Is the solution performant and concise? No unnecessary complexity?

| Score | Description |
|-------|-------------|
| 0     | Extremely inefficient or bloated |
| 3     | Noticeably inefficient |
| 5     | Acceptable efficiency |
| 7     | Efficient with minor improvements possible |
| 10    | Optimal or near-optimal |

## Final Score

```
Final = Correctness * 0.40 + Completeness * 0.25 + Clarity * 0.20 + Efficiency * 0.15
```

Scores are rounded to one decimal place. A passing score is 6.0 or above.

## Grading Scale

| Range | Grade |
|-------|-------|
| 9.0 - 10.0 | A |
| 8.0 - 8.9  | B |
| 6.0 - 7.9  | C |
| 4.0 - 5.9  | D |
| 0.0 - 3.9  | F |
